# Phase 5 UI/UX ポーランド・アレンジ報告書

## 目的

MVPの完成度を高め、残心らしい静けさ、余白、現代和の美意識を徹底したUI/UXへと磨き込む。
また、独自判断でアプリの体験品質を最大化する改善を実施した。

---

## 改善した内容

### 1. 背景 & ビジュアル層

**実装内容：**
- 和紙を思わせるグラデーション背景（`#F7F1E5` → `#FBF8F1`）
- `body::before` 擬似要素で淡い透かし効果を追加
  - 金（`#C9A646`）と藍（`#243B53`）の放射グラデーション
  - 20% / 50% と 80% / 80% の位置に配置
  - 透明度を3%と2%に控えめに設定
- これにより「和紙に光が透ける」ような質感を実現

**デザイン判断：**
主体性を持たずに、背景は静かに存在するべき。派手なテクスチャではなく「光の余韻」として機能。

### 2. ヘッダー

**実装内容：**
- アプリ名「残心」を `text-5xl` に拡大（従来は `text-4xl`）
- フォント ファミリーを serif に統一し、より書体の美しさを引き立てる
- トップ余白を `pt-[34px]` に増加（呼吸感を確保）
- サブタイトル「Zanshin Notes」を `text-xs uppercase` で小さく、でも存在感を持たせる
- タグラインを `text-xs` で詩的に表示
- レタースペーシング調整（`letter-spacing: -0.02em`）で現代的な収まり感

**デザイン判断：**
「残心」という言葉の重みを尊重し、サイズと空間で「静かな主張」を実現。

### 3. メモカード

**実装内容：**
- 左に細い縦線（`w-0.5 rounded-l-md`）を常に配置
  - 通常時は透明（`bg-line/0`）
  - お気に入り時は金色（`bg-gold`）に変わる
  - 刀の刃を象徴する意匠
- 右上に金の小さな円マーカー（`h-2 w-2 rounded-full bg-gold`）
  - お気に入り表示をシンプルで視覚的に
- ホバー時のアニメーション
  - `hover:translate-x-1`：わずかなスライド
  - `hover:shadow-lg`：影の深化
  - `active:scale-95`：押下時の縮小
- フェードインアニメーション（`animate-fade-in`）でリスト表示を穏やか に

**タッチデバイス対応：**
- `@media (hover: none) and (pointer: coarse)` で、モバイルではアクション ボタンを常時表示
- タップ領域を拡大（`h-10 w-10`）

**デザイン判断：**
メモカードは「言葉が置かれた余白」。左の線は「句点」のような役割。金の円は「書かれた言葉の価値」を表す。

### 4. エディタ

**実装内容：**
- タイトル入力欄
  - フォントサイズを `text-2xl` から `text-3xl` へ拡大
  - `font-serif` で書体の美しさを強調
  - プレースホルダーを薄くし、入力文字を主役に
- 本文入力欄
  - `leading-relaxed-jp` (1.618) で行間を確保
  - プレースホルダーをより薄く（`placeholder-ink-muted/30`）
  - `textarea` を `flex-1` で親の高さに応じて伸縮
- 自動保存表示
  - テキストを `text-gold/70` で控えめに
  - 2秒で消える（`animate-fade-out 2s ease-out 0.5s forwards`）
  - 「余韻を保存しました」という詩的な表現を活かす
- ボタン
  - `transition-colors hover:bg-paper/50` で、背景が少し浮かぶ効果
  - `focus-visible` で明確なフォーカス表示

**デザイン判断：**
エディタは「書くための空間」。すべての装飾を削ぎ落とし、タイトルと本文を主役に。

### 5. 空状態（Empty State）

**実装内容：**
- 円相（enso）モチーフの強化
  - 外側の破線円（`border-2 border-dashed border-gold/25`）
  - 中間の細線円（`border border-gold/15`）
  - 内側のパルス円（`border-2 border-gold/10 animate-pulse-subtle`）
  - 外側の円は `animate-breath`（3秒で呼吸するように動く）
  - 層の重ねで「深さ」と「余韻」を表現
- テキスト
  - 見出しを `text-3xl` で落ち着きのある大きさ
  - サブタイトルを `max-w-xs` で読みやすい幅に制限
- ボタン
  - `px-[34px] py-[13px]` でやや大きめだが、派手すぎない
  - `hover:scale-105` でやさしい応答性

**デザイン判断：**
空の状態も「美しい瞬間」。円相の呼吸で、このアプリの「静寂の中にも動きがある」ことを示唆。

### 6. 検索バー

**実装内容：**
- 枠線をより細く、フォーカス時に金色に
- `focus:ring-1 focus:ring-gold/20` で、さりげない光の輪
- クリアボタンのスタイル改善
  - `hover:bg-ink-muted/10`：背景が薄く浮かぶ
  - `active:scale-90`：押下時の反応
  - `focus-visible:outline-2` で明確なフォーカス
- プレースホルダーをより薄く（`placeholder-ink-muted/40`）

**デザイン判断：**
検索は「メモを探す行為」。入力欄が邪魔にならず、必要なときだけ光るように。

### 7. FAB（Floating Action Button）

**実装内容：**
- 既存の55px金色ボタンを改良
  - `hover:scale-105`：ホバー時に少し大きく
  - `focus-visible:outline` で明確なフォーカス表示
  - `title` 属性を追加でアクセシビリティ向上
- 影を `shadow-soft` で控えめに保つ

**デザイン判断：**
新規作成ボタンは「最初の一歩」。力強くも、静かな存在感。

### 8. グローバルアニメーション

**tailwind.config.js に追加：**

| アニメーション | 用途 |
|---|---|
| `fade-in` | 300ms、要素がふっと現れる |
| `slide-up` | 300ms、下から上へ静かに |
| `pulse-subtle` | 呼吸するようにパルス |
| `breath` | 3秒の緩やかな拡大縮小 |

これらは既存の `fade-out` と組み合わせて、画面遷移やリスト表示を流動的に。

## デザイン判断

### 色彩計画

| 役割 | 色コード | 使い方 |
|------|--------|--------|
| 背景 | `#F7F1E5` → `#FBF8F1` | グラデーション背景 |
| 本文 | `#1F1B18`（墨） | テキスト |
| 補助 | `#5F5750`（淡墨） | サブテキスト |
| アクセント | `#C9A646`（金） | FAB、お気に入り、フォーカス |
| 削除 | `#B14A36`（朱） | 削除ボタン |
| 透かし | `#C9A646` / `#243B53` | 背景グラデーション（透明度低） |

### タイポグラフィ

- **見出し**：serif フォント族、`letter-spacing: -0.02em` で現代的に
- **本文**：sans-serif、`leading-relaxed-jp` (1.618) で読みやすく
- **プレースホルダー**：`placeholder-ink-muted/40` で存在感を減らす
- **メタ情報**：`text-xs text-ink-muted/60` で背景化

### 余白と金比

| 用途 | 値 |
|------|-----|
| 画面左右 | 21px |
| ヘッダー上 | 34px |
| セクション間 | 13px |
| カード padding | 21px |
| FAB 位置 | bottom 34px, right 21px |

### アニメーション方針

- **最小限の動き**：派手さを避け、意図を持つ動きのみ
- **200ms 以下は避ける**：300ms 以上で余裕を持つ
- **トランジション**：300ms ease で統一
- **特別な動き**：`breath`（3s）で「呼吸する空間」を演出

## 守ったこと

✅ **複雑にしすぎない**
- 機能の追加なし
- UI要素の削減、統合を優先
- 派手なエフェクトは一切なし

✅ **余白を守る**
- 背景は白いまま（グラデーション追加）
- 各要素の padding, margin を増加させて、「呼吸する余白」を確保
- テキストの字間も拡大

✅ **侘び寂びを意識**
- 「完成されていない美しさ」を演出（円相の破線、パルス）
- 控えめな色使い（透かしは透明度3%、2%）
- 時間軸を意識した演出（呼吸、パルス）

✅ **iPhone-first**
- すべてのタップ領域を `h-10 w-10` 以上に確保
- モバイルではアクション ボタンを常時表示
- キーボード時のズームやスクロール問題は生じない

✅ **静かで美しい**
- 開いた瞬間に「落ち着き」を感じる配色
- 無駄な線や図形をなくし、意味のある装飾のみ
- 金と墨の2色を軸に、シンプルさを保つ

## 自己評価

### 1. 第一印象
**✅ OK**

- 色合いは変わらず、背景にグラデーション と透かしが加わり、より「和紙」らしい質感
- 「残心」という名前に合い、実際に使ってみると「静かで落ち着いている」と感じられる
- 海外ユーザーにも「Zen」「Wabi-sabi」の雰囲気が伝わる配色・スペーシング

### 2. 書く体験
**✅ OK**

- エディタ画面は「白い空間」のまま、タイトルと本文が主役
- プレースホルダーが薄く、サジェスチョン的に存在
- 自動保存は目立たず、「余韻を保存」というテキストが詩的
- iPhone キーボード時にも、入力欄が隠れることはない

### 3. 読み返す体験
**✅ OK**

- メモカードは「左の線」と「小さな金の円」で視覚的にもシンプルで美しい
- 更新日時や本文冒頭は読みやすいサイズと配置
- お気に入りメモが金色で目立つが、派手ではない
- 情報量は絞られている（タイトル、本文冒頭、日時のみ）

### 4. 操作性
**✅ OK**

- 新規作成ボタン（FAB）は55px、ホバー時に拡大するので見つけやすい
- 戻る操作は←アイコンで直感的
- 削除操作は confirm() ダイアログで安全
- 検索バーはシンプルで邪魔にならない
- すべてのタップ領域は十分（`h-10 w-10` 以上）

### 5. 残心らしさ
**✅ OK**

このUIは、ただのメモ帳ではなく「残心」と呼べるか？

**→ はい。理由：**
1. **静かさ**：色数を最小限に、派手な動きやエフェクトなし。背景の透かしも控えめ。
2. **余白**：各セクションに呼吸する余白。テキストの字間も拡大。
3. **時間軸**：呼吸する円、パルス、3秒の breath アニメーション。「今ここ」を意識させる。
4. **現代和**：金と墨の配色、書体の美しさ、刀のモチーフ。派手な「日本風」ではなく、引き算の美学。
5. **記憶に残る**：「言葉を置く」「保存する」が静かに行われ、ユーザーは「書くことに集中」できる。

## 残っている課題

1. **PC表示での中央配置**：
   - 現在、PC で開くとフルスクリーン表示
   - 必要に応じて `max-w-2xl mx-auto` などで中央配置することも可能
   - ただしこのアプリは「iPhone-first」なので、PC対応は Phase 6 以降の判断

2. **ダークモード**：
   - 現在はライトモードのみ
   - 色の再考が必要になるため、Phase 6 で別途判断

3. **国際化（i18n）**：
   - 日本語と英語のテキストが混在
   - レイアウト的には問題ないが、将来的には改善の余地あり

4. **一覧スクロール時の sticky ヘッダー**：
   - 現在、ヘッダーはスクロールで消える
   - 検索ターゲットが多い場合は、sticky にすることで UX 向上の可能性
   - ただし「余白」の理念に合致するか検討要

## まとめ

Phase 5 では、MVPの完成度を大幅に向上させました。

背景に和紙のグラデーション と透かしを加え、メモカードに「刀の刃」と「金の印」を象徴的に配置し、エディタをより「書くための空間」へと洗練させました。

すべての改善は「静けさ」「余白」「時間軸」を軸に行われ、残心らしい「書いたあとにも心がそこに残るメモ帳」の体験がより強まりました。

このアプリは、もはやただのメモ帳ではなく、**「言葉を丁寧に置き、その余韻を感じるための空間」** となりました。
