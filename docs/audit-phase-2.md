## 9. Phase 3 実装前の最終方針

Phase 3では以下を守ること：

- Vite + React + TypeScript + Tailwind でMVPを作る
- localStorage 保存から開始する（`lib/storage.ts` に分離）
- メモ一覧、作成、編集、削除、自動保存、検索、お気に入りを実装する
- iPhone-first で設計する
- 余白と行間を大切にする
- 黄金比スケール `4 / 8 / 13 / 21 / 34 / 55 / 89` を活用する
- 機能を増やしすぎない（MVP仕様に明記されたもののみ）
- Cloudflare Pages へのデプロイは MVP 完成後のみ行う
- Safe Area 対応を実装する（iOS PWA / Capacitor 対応）
- コンポーネントを `src/components/` に整理する
